Stop Rule Guide

Define stop, pause, and re-check conditions in advance so the search cannot expand forever.

Decide when to leave before you enter

A search without a stop rule expands to fill whatever time you give it. The cure is to write the exit conditions before you start, so that stopping is a decision you already made — not an impulse you reach for only after you are tired.

Stop rules

  • No product type written. Without a type, every aisle looks relevant. Stop and write the type before continuing.
  • The category keeps drifting. Two or more categories at once means no single question. Stop and pick one window.
  • A must-have is missing. A candidate fails a hard condition but still looks attractive. Stop and set it aside; do not soften the rule.

Pause rules

  • The brief has not changed the outcome. When the brief no longer filters anything, pause and rewrite it.
  • The same window is being re-opened. Re-reading the same listings without a new question is a sign to pause and re-check what is still open.

Re-check rules

  • Open questions are growing. More questions than answers means you are collecting, not deciding. Stop and re-check each question on the current page.
  • The page differs from the sheet. The selected option, size, or price on the current page is the live fact. Re-check it against the brief before relying on a remembered label.

A worked set of rules

  1. Stop if a candidate fails the “fits a 13″ laptop” must-have — set it aside.
  2. Pause if the brief has not ruled out anything in the last three windows — rewrite it.
  3. Re-check the strap length and included parts on the current page before deciding.
